Our illustration style is guided by a set of principles outlined earlier in this guidance. To keep illustrations consistent, avoid the following:

{% grid { columns: { tablet: 2 }, classes: 'govuk-!-margin-bottom-0' } %}

<div class="app-border app-border--top">

Don’t use gradients.

</div>
<div>

![A suitcase and a briefcase in a gradient colour with a red line crossing the whole image.](./incorrect-gradients.svg)

</div>

<div class="app-border app-border--top">

Don’t use patterns.

</div>
<div>

![A boy holding a box that has a pattern on it with a red line crossing the whole image.](./incorrect-patterns.svg)

</div>

<div class="app-border app-border--top">

Don’t use low contrasting colours.

</div>
<div>

![A collection of items, all with low colour-contrast: an abstract document, a webpage, and icons in a design-tool, with a red line crossing over all of them.](./incorrect-lowcontrast.svg)

</div>

<div class="app-border app-border--top">

Don’t add facial expressions to characters.

</div>
<div>

![An illustration of a woman shown with a pair of eyes, with a red line crossing the whole image.](./incorrect-nofaces.svg)

</div>

<div class="app-border app-border--top">

Don’t use outlines or strokes.

</div>
<div>

![A paperclip holding a document with a black stroke around them both and a red line crossing the whole image.](./incorrect-nostrokes.svg)

</div>

<div class="app-border app-border--top">

Don’t use three dimensional assets, However, layering of 2D assets to create a sense of depth is allowed.

</div>
<div>

![A 3D image of a woman holding a box and a red line across the whole image.](./incorrect-threed.png)

</div>

## Incorrect contextual usage

- Don’t include imagery that is of a sensitive nature.
- Don’t create purely decorative illustrations.
- Don’t use humour or satire.
- Avoid assumptions about gender, age, disability, ethnicity, family ## structure or employment.
